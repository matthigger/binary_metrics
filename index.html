Binary metrics, visually

Every binary classification metric is a ratio of counts from one 2 × 2 table.

The confusion matrix

Goal: describe how well a binary classifier (here, a medical test) does, with a number that answers the question you care about.

Approach: count the samples in each of the four cells: truth (row) by prediction (column). Every metric divides some of the cells by a row, a column or the whole table.

Predict 0 Predict 1
Truth 0TNFP
Truth 1FNTP

Edit any count in the table, or drag the lines in the mosaic (the total stays fixed). Hover a metric to light up its numerator (filled) and denominator (outlined); hover a cell to see which metrics use it.

Try this

  • Step through the tour with Next or the arrow keys.
  • Pick Mammogram. A woman's mammogram is positive: how likely is it that she has cancer? Guess before you look at precision.
    AnswerAbout 9%. The 990 women without cancer, at a 9% false alarm rate, give 89 false positives, swamping the 9 true positives. A rare condition makes most positives false, even for a good test.
  • Pick Always say no. Its accuracy beats the mammogram's. Which metrics expose it?
    AnswerTPR is 0%: it catches no one. Balanced accuracy is 50%, F1 is 0 and precision is undefined (0 / 0), since it never predicts 1.
  • On Strep test, drag the line between the rows. Which metrics stay put?
    AnswerThe row ratios (TPR, FNR, TNR, FPR): each uses only one true class. Prevalence, accuracy and the column ratios (precision, NPV) move.
  • Raise TN from 601 to 6,000. Which metrics change?
    AnswerOnly those whose formula contains TN: accuracy, prevalence, TNR, FPR, NPV, FOR and balanced accuracy. TPR, precision and F1 do not use TN, so they do not move.
  • Build a table with precision 100% but recall 10%. What kind of test is it?
    AnswerFor example TP = 37, FP = 0, FN = 333: a cautious test that flags only the sure cases. Every flag is right, but it misses most of the positives.

Mosaic: each row is a true class (height ∝ its count), split by the prediction, so area ∝ count. Hatched cells are mistakes. Drag a line to move samples between cells.

The ROC curve

Goal: summarize a classifier over every threshold, not just one: the whole trade-off between catching the 1s (TPR) and false alarms on the 0s (FPR).

Approach: a classifier gives each sample a score (c · x for the perceptron or LDA, σ(c · x) for logistic regression) and predicts 1 when score ≥ t. Each threshold t gives one confusion matrix, so one point (FPR, TPR). Sweeping t from high to low traces the ROC curve.

AUC = area under the ROC curve = P(a random Truth 1 sample outscores a random Truth 0 sample)

Lowering t past a Truth 1 sample steps the curve up (one more TP); past a Truth 0 sample, right (one more FP). The scores here are drawn from two normal distributions whose means differ by the separation.

Try this

  • Press Sweep, or drag the threshold from right to left. Why does the curve only ever move up or right?
    AnswerLowering t only adds samples to Predict 1. Each added sample is a Truth 1 (TP + 1: up by 1 / #Truth 1) or a Truth 0 (FP + 1: right by 1 / #Truth 0).
  • Set the separation to 0. Where does the curve go?
    AnswerNear the diagonal, with AUC near 0.5: the scores carry no information about the class, so at any threshold the classifier flags the same share of each class (TPR ≈ FPR). That is guessing.
  • Make the separation negative: the curve sinks below the diagonal. Now press Flip scores.
    AnswerWorse than guessing is useful: predict the opposite. Flipping every score mirrors each point (FPR, TPR) to (1 − FPR, 1 − TPR) and turns AUC into 1 − AUC.
  • Turn on AUC as pairs and hover the cells. Why is the area under the staircase the share of correctly ordered pairs?
    AnswerEach column is one Truth 0 sample and each row one Truth 1 sample (both sorted high to low), so each cell is one pair. A column's height under the curve is the number of Truth 1 samples that outscore that Truth 0 sample.
  • Turn on Show whole curves and move the prevalence from 50% to 5%. Which curve keeps its shape: ROC or PR?
    AnswerROC: TPR and FPR each use one true class, so prevalence does not enter (the wiggles are sampling noise). Precision mixes the classes: with few Truth 1s the PR curve sinks toward the 5% guessing line.
  • Where would you put the threshold for a strep test? For a spam filter?

Drag the threshold on the scores, or drag along either curve. The arrow keys move it one sample.

Would you rather?

Goal: choose between two classifiers that are described in different terms.

Approach: turn each description into counts. N and the prevalence give the row totals; each clue fills in more of the matrix. Then compute what the goal asks for.

Two clues plus the prevalence pin down the whole confusion matrix. Keys: a or b to choose, Enter for the next round.

Try this

  • Guess from your gut first, then work it out. How often is the gut right?
  • Watch for clues about the wrong class: a 99% specificity says nothing about how many positives are caught.
  • For a cost goal, compute (cost of a miss) × FN + (cost of a false alarm) × FP for each.
  • When the condition is rare, compare accuracy with F1. Which one did the goal ask for?
